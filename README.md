# Νούση Παναγιώτα — Burgundy Authority

Ελληνικό demo της επιλεγμένης κατεύθυνσης 2.

## GitHub Pages

Δημόσιο demo: [chanturia.github.io/panagiota-nousi-lawyer](https://chanturia.github.io/panagiota-nousi-lawyer/).

Το GitHub Actions workflow ελέγχει και δημοσιεύει αποκλειστικά τον φάκελο `site/` μετά από αλλαγές του στον κλάδο `master`. Μπορεί επίσης να εκτελεστεί χειροκίνητα από το Actions → Deploy GitHub Pages.

Κάθε HTML περιλαμβάνει μία εγκατάσταση Cloudflare Web Analytics, διατηρημένη στο `build.py`. Η πολιτική περιεχομένου επιτρέπει το script και το endpoint του Cloudflare. Τα πεδία της φόρμας δεν αποστέλλονται στα analytics.

## Προεπισκόπηση

Από αυτόν τον φάκελο:

```powershell
rtk proxy python -m http.server 8768 --bind 127.0.0.1 --directory site
```

Ανοίξτε http://127.0.0.1:8768/index.html. Ο server προβάλλει μόνο τον φάκελο `site/`. Το localhost λειτουργεί στον συγκεκριμένο υπολογιστή και δεν είναι δημόσιος σύνδεσμος.

Δεν απαιτείται εγκατάσταση πακέτων ή build για την προεπισκόπηση μέσω του τοπικού server.

Ο κώδικας των κοινών στοιχείων και το περιεχόμενο βρίσκονται στο `build.py`. Μετά από αλλαγές σε αυτό, εκτελέστε `rtk proxy python -X utf8 build.py` και `rtk proxy python -X utf8 check_static.py`. Η αναδημιουργία ανακτά το stylesheet των Google Fonts· το έτοιμο site χρησιμοποιεί αποκλειστικά τα τοπικά αρχεία γραμματοσειρών. Τα CSS και JavaScript βρίσκονται στα `site/assets/style.css` και `site/assets/site.js`.

## Όρια του demo

Η φόρμα κάνει μόνο τοπικό έλεγχο πεδίων και εμφανίζει αποτέλεσμα δοκιμής. Δεν στέλνει ούτε αποθηκεύει δεδομένα. Οι σύνδεσμοι τηλεφώνου, email και χάρτη είναι ξεχωριστές ενέργειες του επισκέπτη.

Οι εικόνες είναι δημιουργίες AI για την παρουσίαση της αισθητικής και δεν απεικονίζουν το πραγματικό γραφείο. Τα στοιχεία και οι τομείς δραστηριότητας βασίζονται στην υπάρχουσα ιστοσελίδα και χρειάζονται επιβεβαίωση από το γραφείο πριν από επίσημη χρήση.

Το δημόσιο demo διατηρεί οδηγίες `noindex,nofollow`. Δεν περιλαμβάνει CMS, βάση δεδομένων ή υπηρεσία αποστολής email.
